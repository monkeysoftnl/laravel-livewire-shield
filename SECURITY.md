# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| 1.x | No; upgrade to 2.x |

## Reporting a vulnerability

Please **do not** open a public issue, discussion or pull request for a security problem.

Report it privately through either channel:

- GitHub: **Security → Report a vulnerability** on this repository (private vulnerability reporting).
- E-mail: security@monkeysoft.nl

Please include the affected version, a description, and steps to reproduce. You will get an acknowledgement within 5 working days. We aim to ship a fix or a mitigation within 30 days, and we will agree a disclosure date with you.

## Scope

In scope: code in this package.

Vulnerabilities in Livewire, Laravel or other dependencies belong with their maintainers:

- Livewire: https://github.com/livewire/livewire/security
- Laravel: https://laravel.com/docs/contributions#security-vulnerabilities
